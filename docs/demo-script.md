# اسکریپت ویدیو دمو (۵+ دقیقه)

هدف: نمایش تمام قابلیت‌ها روی **دسکتاپ و موبایل**.

## بخش ۱ — معرفی (۰:۳۰)
- معرفی پروژه: «داشبورد تحلیلی برای پذیرندگان زرین‌پال»
- توضیح یک‌خطی: بینش‌های قابل اقدام + قابل ردیابی برای پذیرنده غیرتکنیکال

## بخش ۲ — اجرا و معماری (۱:۰۰)
- اجرای `docker compose up -d --build`
- نمایش ساختار پروژه (monorepo): api / frontend
- معماری: CSV → DuckDB → FastAPI → Next.js

## بخش ۳ — نمای کلی پذیرنده (۱:۰۰)
- کارت‌های KPI: حجم، تعداد تلاش، نرخ موفقیت، سهم کارمزد، روزهای فعال
- توضیح اینکه هر عدد از کجا می‌آید ("چطور محاسبه شد؟")

## بخش ۴ — تحلیل زمانی (۰:۳۰)
- نمودار روند روزانه/هفتگی
- مقایسه فصلی در صورت وجود داده کافی

## بخش ۵ — بینش‌های قابل اقدام (۱:۰۰)
- پنل پیشنهادهای هوشمند: اولویت‌بندی + توضیح محاسبه هر پیشنهاد
- مقایسه با هم‌صنفی‌ها (صدک‌ها)

## بخش ۶ — ردیابی‌پذیری (۰:۴۵)
- پنل «ردیابی محاسبات»: استعلام SQL + منبع هر عدد
- کلیک روی هر عدد → نمایش نحوه محاسبه

## بخش ۷ — موبایل (۰:۴۵)
- باز کردن در viewport موبایل (DevTools)
- منوی همبرگری، چیدمان تک‌ستونه، کارت‌های خوانا

## بخش ۸ — جمع‌بندی (۰:۳۰)
- خلاصه قابلیت‌ها + معیارهای چالش
- تأکید بر اینکه adjusted_fee نسبی است، نه مطلق
